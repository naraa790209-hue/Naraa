💰 Худалдагчийн заавар (Танд зориулав)

ЭНЭ БАРИМТЫГ БУСДАД БИТГИЙ ӨГӨӨРЭЙ. Энэ нь зөвхөн танд зориулсан удирдлагын заавар. Энд лиценз үүсгэх, худалдах, хянах бүх алхам бичсэн.

📁 Хавтасны бүтэц

ХавтасЗориулалт
ХӨГЖИМ_ӨЛЗИЙ_СИСТЕМ/Эх хувь — таны өөрийн ажлын систем. Хэзээ ч бусдад өгөхгүй.
ХӨГЖМИЙН_СИСТЕМ_ТҮГЭЭХ/Түгээх хувь — цэвэрлэгдсэн, лицензийн шалгалттай. Багшид ZIP болгож зарна.

🎫 1. Supabase-д лицензийн хүснэгт үүсгэх (нэг удаагийн ажил)

Таны Supabase (dehxrmupnbilwlxsovpi.supabase.co) дотор licenses нэртэй хүснэгт үүсгэнэ.

  1. Supabase dashboard → SQL Editor → New query
  2. Доорх кодыг хуулж наагаад Run дар:
create table if not exists licenses (
  key text primary key,
  teacher_name text,
  school text,
  location text,
  status text default 'active',           -- active | disabled
  machine_fp text,                         -- эхний ажиллуулахад бөглөгдөнө
  created_at timestamptz default now(),
  activated_at timestamptz,
  sold_price int,
  contact text,                            -- утас/facebook
  notes text
);

-- ADD & UPDATE — багш идэвхжүүлэх боломжтой байх
alter table licenses enable row level security;
create policy "anon_read" on licenses for select using (true);
create policy "anon_update_own" on licenses for update using (true) with check (true);
📌 Policy-ийг ил байлгаж байна — багш өөрийн машины fingerprint-ыг эхний удаа бүртгэх ёстой тул. Хүсвэл дараа нь server-side function хийж хамгаалалт нэмж болно.

🎟️ 2. Багшид зарах бүрд лиценз үүсгэх

А. Түлхүүр үүсгэх

Дурын код сонгож болно (жишээ нь: HGJM-2026-001). Санамсаргүй болгож болно:

-- Supabase SQL Editor-т:
insert into licenses (key, teacher_name, school, location, sold_price, contact)
values ('HGJM-2026-001', 'Б. Дуламсүрэн', '15-р цэцэрлэг', 'Улаанбаатар БЗД', 250000, '99001234');

Б. Багшид дараах 3-ыг илгээх

  1. ZIP файл — ХӨГЖМИЙН_СИСТЕМ_ТҮГЭЭХ хавтасны ZIP хувилбар
  2. Лицензийн түлхүүр — HGJM-2026-001
  3. Заавар — ZIP дотор ЗААВАР_БАГШИД.html байгаа

📊 3. Худалдсан лицензээ хянах

Supabase Table Editor → licenses дарж бүх худалдсан лицензийг харна:

  • activated_at — багш анх суулгасан огноо (хоосон бол дутуу)
  • machine_fp — багшийн компьютерийн ID
  • status — active эсвэл disabled

🚫 4. Лиценз цуцлах (дүрэм зөрчигдвөл)

update licenses set status = 'disabled' where key = 'HGJM-2026-001';

Дараагийн удаа багш системээ ажиллуулахад Лицензийн алдаа гарч, систем нээгдэхгүй.

🔄 5. Багш компьютераа солих хүсэлт ирвэл

-- machine_fp-ыг цэвэрлэ, багш дахин суулгаж болно
update licenses set machine_fp = null where key = 'HGJM-2026-001';

📦 6. Түгээх ZIP бэлдэх

  1. File Explorer → ХӨГЖМИЙН_СИСТЕМ_ТҮГЭЭХ хавтас дээр баруун товч
  2. Send to → Compressed (zipped) folder
  3. ХӨГЖМИЙН_СИСТЕМ.zip файл үүснэ (2-3 MB)
  4. Google Drive / MEGA-д байршуулж линкээр илгээ

🛡️ Хамгаалалтын түвшин

Одоогийн хамгаалалт:
  • ✅ Лицензийн онлайн шалгалт бүр удаа асаахад ажиллана
  • ✅ Машины fingerprint — нэг лиценз = нэг компьютер
  • ✅ Багш бүрийн нэр, цэцэрлэг header-т ил гардаг усны тэмдэг
  • ✅ Setup wizard-гүйгээр систем нээгдэхгүй (config.js байхгүй бол)
  • ✅ Багш бүр өөрийн Supabase — таны дата бүрэн тусгаарлагдсан
Хязгаарлалт: HTML/JS код нь ил тул техник мэддэг хүн лицензийн шалгалтыг устгах онолын боломжтой. Гэхдээ энгийн багшийн хувьд бараг боломжгүй, бас үүнд оролдох сонирхол багатай (үнэ хямд, шаардлагатай бол дахин авах хялбар).
